## 📋 Описание проекта
Данное приложение является результатом прохождения курса по Android-разработке. Оно объединяет в себе несколько модулей, демонстрирующих работу с ключевыми компонентами системы: от простейших интерфейсов до сложных архитектурных решений с использованием сетевых запросов и баз данных.

## 🚀 Основные возможности (Лабораторные работы 5-19)
В ходе разработки были реализованы следующие задачи:
*   **Работа со списками (ЛР 5, 14):** Использование `RecyclerView` для эффективного отображения данных.
*   **Локальные БД (ЛР 12):** Реализация CRUD-интерфейса (создание, чтение, обновление, удаление) пользователей с помощью SQLite.
*   **Сетевое взаимодействие (ЛР 13, 14, 15):** 
    *   Интеграция библиотеки **Retrofit**.
    *   Асинхронные запросы к REST API (JSONPlaceholder) через **Kotlin Coroutines**.
    *   Обработка сетевых ошибок.
*   **Геолокация и Карты (ЛР 16):** Работа с **OSMDroid** (OpenStreetMap) для отображения местоположения пользователя без использования проприетарных Google-сервисов.
*   **Тестирование и отладка (ЛР 17):** 
    *   Написание **Unit-тестов** (JUnit) для проверки логики.
    *   Написание **UI-тестов** (Espresso) для проверки взаимодействия с интерфейсом.
*   **Сборка и подпись (ЛР 18):** Настройка конфигурации для Release-сборок, использование `minifyEnabled` и `shrinkResources` для оптимизации размера.
*   **Архитектура MVVM (ЛР 19):** Разделение проекта на слои Data, Domain и Presentation с использованием `ViewModel` и `LiveData`.

## 🛠 Технологический стек
*   **Язык:** Kotlin
*   **Библиотеки Jetpack:** ViewModel, LiveData, Lifecycle, Fragment-KTX.
*   **Сеть:** Retrofit 2, Gson Converter.
*   **Карты:** OSMDroid Android SDK.
*   **БД:** SQLiteOpenHelper.
*   **Тесты:** JUnit 4, Espresso Core.

## 📦 Основные зависимости
Проект использует следующие ключевые зависимости (из `libs.versions.toml`):
- `androidx.appcompat` — поддержка современных компонентов на старых версиях Android.
- `com.google.android.material` — Material Design компоненты.
- `com.squareup.retrofit2:retrofit` — работа с API.
- `org.osmdroid:osmdroid-android` — карты.
